# no4eye

Мягкие практики дыхания, самоценности и открытости. Статический сайт без сборки: один файл `index.html`, работает офлайн как PWA.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | Всё приложение: страницы, стили и скрипты |
| `manifest.json` | Данные для установки на экран «Домой» |
| `sw.js` | Офлайн-режим и кэш |
| `icons/icon-192.png`, `icons/icon-512.png` | Иконки приложения |
| `icons/apple-touch-icon.png` | Иконка для iPhone |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |
| `README.md` | Это описание |

## Запуск на GitHub Pages

1. Загрузи все файлы в корень репозитория, папку `icons` с содержимым тоже.
2. В репозитории: Settings, Pages, Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<имя>.github.io/<репозиторий>/`.

## Что заменить перед запуском

- Ссылки на Telegram: в `index.html` найди `https://t.me/` (кнопка «Все отзывы» и окно «Поддержка») и подставь свои.
- Название `[НАЗВАНИЕ]`, ссылки на оплату, реквизиты, плейсхолдеры в квадратных скобках `[...]`.
- Отзывы-заглушки: замени настоящими, опубликованными с согласия авторов.

## Обновления

Измени `CACHE = 'no4eye-v1'` в `sw.js` на `v2`, `v3` и так далее при каждом заметном обновлении, иначе у людей может остаться старая версия.
