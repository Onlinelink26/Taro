# no4eye — практики для близости с собой

Мягкое веб-приложение с практиками дыхания, самоценности, границ и открытости.  
4-недельные программы, калькулятор арканов, трекер настроения, челлендж 21 день, атмосфера (белый шум), тёплый бот и анонимная стена тепла.

## Как открыть

Просто открой `index.html` в любом современном браузере (Chrome, Safari, Firefox, Edge).

Или запусти локальный сервер:

```bash
# Python
python -m http.server 8000

# или Node
npx serve .
```

Затем открой http://localhost:8000

## Основные возможности

- **Виджет «Сегодня»** — сразу видно практику дня
- **Дыхание 4-6** — визуальная анимация круга
- **Тёмная / светлая тема** — переключается кнопкой в шапке
- **Атмосфера** — процедурные звуки (дождь, камин, море, ветер, лес, ночь) через Web Audio API
- **Трекер настроения** + график за 7 дней
- **Челлендж «21 день нежности»**
- **Дневник** и **дни тишины**
- **Стена тепла** — анонимные маленькие победы
- **Тёплый бот** — бережные ответы
- **Калькулятор арканов**, карта дня, 4-недельные программы
- **SOS** — плавающая кнопка экстренной помощи
- Всё сохраняется локально (localStorage)

## Офлайн

После первого открытия приложение может работать без интернета (Service Worker кэширует `index.html`).

## Важно

- Это демо. Оплата не подключена («Купить» просто открывает доступ внутри макета).
- Звуки генерируются процедурно в браузере — настоящие аудиофайлы не используются.
- Для продакшена нужно подключить реальную оплату (ЮKassa / Robokassa / Telegram Stars и т.д.) и, при желании, заменить процедурные звуки на качественные записи.
